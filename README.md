# 🚢 Titanic Dataset AI Chat Agent

## 📌 Overview
This project is an AI-powered chat agent that answers questions about the Titanic dataset using natural language.

It uses:

- FastAPI (Backend)
- LangChain + Ollama (AI Agent)
- Streamlit (Frontend)
- Pandas & Matplotlib (Data Analysis)

---

## ⚙️ Features

✔ Ask natural language questions  
✔ Get textual insights  
✔ Generate visualizations  
✔ Interactive chat interface  

---

## 📊 Example Queries

- How many passengers survived?
- Average fare?
- Show age distribution
- Survival rate by gender

---
